## Real work problem

After M0.2, the repository has a local vault folder contract under:

```text
storage/personal_memory/<person-id>/vault/
```

The vault defines required folders and future front matter, but it does not yet define or test a minimal Obsidian-compatible graph navigation convention.

Therefore, a real user cannot yet rely on the Personal Twin workspace to answer daily navigation questions such as:

```text
Which meeting created this decision?
Which decision created this task?
Which source supports this decision note?
Which lesson came from this completed task?
Which project is this work item attached to?
```

Without a bounded M0.3 problem definition, graph work could drift into visual feature volume, unreviewed knowledge promotion, or false evidence authority instead of improving real daily work continuity.
