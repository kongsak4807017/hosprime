# HOSPRIME MASTER CONTEXT

## Product Name
HosPrime

## Product Category
Health Organization Operating System / Institutional Intelligence Platform / Public Health Brain

## Core Thesis
Healthcare organizations do not only need HIS, EMR, dashboards, or chatbots. They need an operating system that preserves institutional memory, connects people and roles to knowledge, supports executive decisions, and creates AI workforce capacity where human capacity is limited.

## Ultimate Platform Components
1. Knowledge Oracle
2. Organization Memory
3. Executive Twin
4. AI Backoffice Workforce
5. Provincial Health Brain

## Strategic Differentiation
HosPrime is not:
- HIS replacement only
- Dashboard only
- RAG chatbot only
- AI assistant only

HosPrime is:
- Digital nervous system of a health organization
- Institutional memory platform
- Digital public health workforce
- Executive intelligence system
- Provincial Health Brain foundation

## Core Value Proposition
1. Preserve knowledge when people retire or transfer.
2. Reduce time spent finding documents and preparing reports.
3. Convert meetings and decisions into reusable memory.
4. Support executives with daily briefs and strategic risk radar.
5. Provide backoffice AI workers to maintain data, knowledge, governance, and agents.
6. Forecast future risks and resource needs.
7. Improve organizational continuity and resilience.

## Product Evolution
Milestone 1: Knowledge Oracle MVP
Milestone 2: Organization Memory Platform
Milestone 3: Executive Twin Platform
Milestone 4: AI Backoffice Workforce Platform
Milestone 5: Provincial Health Brain

## Foundational Rule
Knowledge before AI.

Ontology → Knowledge → Memory → Twin → Agent → Forecast → Health Brain.
