# Example Person Placeholder

This directory is a structural example for a local Personal Twin workspace.

It is not a real person profile and must not be treated as a Person Memory record. It exists only to make the Milestone 0.2 vault contract visible in the repository.

## Boundary

```text
EXAMPLE_PERSON_IS_REAL_PERSON = false
PERSON_MEMORY_RECORD_CREATED = false
REAL_PERSONAL_CONTENT_INCLUDED = false
PATIENT_OR_SENSITIVE_CONTENT_INCLUDED = false
ORGANIZATIONAL_MEMORY_PROMOTION_CLAIMED = false
RAG_ACTIVATION_CLAIMED = false
```

## Expected child path

```text
storage/personal_memory/example-person/vault/
```

The child `vault/` directory documents the future note contract and required note folders.
